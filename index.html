        Model card · 01 / 05 · Medical computer vision

        CrohnSight

        Image classification · severity grading

        0.992AUROC, lesion vs normal (CrohnIPI)
        Problem
        Reading a capsule-endoscopy study means checking tens of thousands of small-bowel frames by eye. Crohn's lesions are small and easy to miss.
        Approach
        An ensemble of 10 EfficientNet-B2 models (5 folds × 2 seeds) at the native 320 px finds lesions in 7 classes, grades severity in 4 tiers and draws a heat-map over each lesion. It is exported to ONNX and runs offline on an ordinary CPU. Add-ons cover ulcerative-colitis Mayo grading and flare-risk forecasting.
        Evaluation
        Lesion vs normal accuracy96.7% (best published 94.6%)
        Severity, quadratic weighted κ0.94
        External test, Kvasir-CapsuleAUROC 0.944, no retraining
        Stack
        • PyTorch
        • EfficientNet-B2
        • ONNX Runtime
        • FastAPI
        • Next.js
        • Docker
        Limits
        Research prototype, not a medical device. Telling a whole lesion video from a lesion-free one is near chance (study AUROC 0.57). The README reports this openly.
        Authors
        With Hil Kalathiya and Chetan Gadhiya · PDEU minor project, guided by Prof. Dr. Babalu Kumar Singh

        Model card · 02 / 05 · Multi-agent LLM system

        Enterprise Agentic RAG Orchestrator

        Retrieval-augmented generation · agent routing

        0.81RAGAS faithfulness
        Problem
        Enterprise questions mix document lookups, database queries and actions such as sending email. A single RAG chain answers them badly or unsafely.
        Approach
        A LangGraph Supervisor → Worker → Validator graph routes each query to Corrective RAG, NL-to-SQL, a human-in-the-loop email tool or chat. Retrieval is hybrid (Qdrant dense + BM25), reranked with a CrossEncoder and expanded from 200- to 800-token parent chunks, with an LLM grader that rewrites weak queries. A semantic cache, prompt-injection guards and Fernet encryption protect it.
        Evaluation
        Context precision1.00
        Context recall0.90
        Answer relevancy0.75

        Model card · 03 / 05 · Reinforcement learning environment

        OpenEnv Data-Cleaning Agent

        Sequential decision-making · data quality

        0.967PPO grader score on hard-clean
        Problem
        Cleaning a messy table takes many small, ordered decisions. Can an agent learn them, and can its score be checked honestly?
        Approach
        An OpenEnv environment over pandas tables with reproducible (task, seed) episodes and a hidden clean ground truth. Potential-based reward shaping makes going in circles worthless, and a separate grader scores the final table. The benchmark compares a PPO agent (400k steps, exported to NumPy), a zero-shot Llama 3.1 8B agent and rule-based baselines, served over FastAPI and WebSocket with a Gradio demo.
        Evaluation
        Improvement over doing nothing+0.917 on hard-clean
        Invalid-action rate (PPO)0.0%
        Llama 3.1 8B zero-shot0.838 on hard-clean
        Stack
        • OpenEnv
        • Stable-Baselines3 PPO
        • Llama 3.1 8B
        • Pydantic
        • FastAPI
        • Docker
        • HF Spaces
        Limits
        The data is synthetic, and Q is only a proxy for quality, which is why a separate grader exists.

        Model card · 04 / 05 · MLOps + explainability

        Explainable Student Performance

        Tabular classification · XAI

        9models benchmarked, explained with SHAP + LIME
        Problem
        A model that predicts which students will struggle is only useful if teachers can see why it made each prediction.
        Approach
        Pandera-validated data and a ColumnTransformer pipeline feed a benchmark of 9 models: linear, tree ensembles, XGBoost, CatBoost, LightGBM, a PyTorch MLP, a PyTorch LSTM and FLAML AutoML. SHAP and LIME explain each prediction, and Spearman rank correlation measures how far the two explanations agree. MLflow tracks runs, FastAPI serves the model and Streamlit shows it.
        Evaluation

        Model card · 05 / 05 · Generative vision research

        DCGAN Reproducibility+

        Image generation · interpretability

        5stability fixes over the 2015 paper, each documented
        Problem
        The 2015 DCGAN is famously unstable, and most re-implementations show only a grid of blurry samples, never what the networks learned inside.
        Approach
        Keeps Radford et al.'s all-convolutional architecture but swaps in an LSGAN loss, Spectral Normalization, a Xavier/Kaiming initialisation, discriminator dropout and label smoothing. A custom GANAnalyzer hooks into the layers to show learned filters, mid-layer feature maps and the separation of D(x) from D(G(z)).
        Evaluation
        DatasetCIFAR-10, 25 epochs
        DiagnosticsFilters, feature maps, D(x) vs D(G(z)) histograms
        BaselineRadford et al., arXiv 1511.06434
        Stack

        • LSGAN
